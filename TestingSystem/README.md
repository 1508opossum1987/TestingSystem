# Тестовая система для младших школьников

Система тестирования с ролями `admin`, `teacher`, `student`.  
Поддерживает темы «Математика» и «Окружающий мир», уровни сложности (1–4 классы),  
оценку результатов и логирование ответов в текстовые файлы.

---

## Технологии

- PHP 8.x
- Laravel 10/11
- PostgreSQL
- Blade + TailwindCSS / Bootstrap

---

## Функциональные возможности

### Пользователи и роли
- Регистрация с подтверждением email
- Авторизация (email + пароль)
- Роли: **admin**, **teacher**, **student**

### Личный кабинет
- Просмотр и редактирование профиля
- Смена пароля

### Тестирование
- Тесты формируются по теме и уровню (классу)
- Вопросы: один правильный ответ (легко расширяется)
- Подсчёт оценки по шкале:
    - 81–100% → 5
    - 61–80% → 4
    - 41–60% → 3
    - ≤40% → 2

### Результаты и логи
- Сохранение результатов в БД
- При первой регистрации создаётся `.txt`-файл с логами ответов по каждому тесту
- Файл хранится на диске, путь — в БД

### Административная часть
- Управление пользователями
- Добавление тем (математика / окружающий мир)
- Управление уровнями вопросов
- CRUD вопросов и тестов

### Для учителя (teacher)
- Просмотр результатов учеников
- Редактирование вопросов (в рамках своих тем)

---

## Структура базы данных (основные таблицы)

- `users` — пользователи с ролями
- `topics` — темы (математика, окружающий мир)
- `question_levels` — уровни (1–4 класс)
- `questions` — вопросы (тема, уровень, текст, варианты, ответ)
- `tests` — тесты (набор вопросов)
- `test_question` — связь тестов и вопросов (many-to-many)
- `results` — результаты прохождения
- `user_logs` — ссылки на txt-логи

> PostgreSQL, JSON-поля для вариантов ответов и ответов пользователя.

## Порядок установки и запуска

### 1. Клонирование репозитория
```bash
git clone https://github.com/1508opossum1987/TestingSystem.git
cd TestingSystem
```

### 2. Настройка окружения
```bash
cp .env.example .env
```
Отредактируйте .env
```bash
DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=testingsystem
DB_USERNAME=postgres
DB_PASSWORD=************
```

### 3. Установка зависимостей
```bash
composer install
```

### 4. Генерация ключа
```bash
php artisan key:generate
```

### 5. Миграции и начальные данные
```bash
php artisan migrate --seed
```

### 6. Запуск сервера
```bash
php artisan serve
```
